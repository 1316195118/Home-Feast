## 一、目标风格（基准）

以 `宫保鸡丁` 为基准图，提取出的统一语言：

| 维度 | 标准 |
|---|---|
| 视角 | 正俯拍 flat-lay，不偏斜 |
| 桌面 | 浅色木纹桌面，纹理可见 |
| 盛器 | 米色 / 陶土色宽口陶碗陶盘（带斑点质感） |
| 光线 | 左上柔光，碗下有柔和阴影，酱汁有高光 |
| 构图 | 4:3，碗沿完整、碗与桌面之间留出明显空白 |
| 色调 | 暖调、低对比、自然 |
| 禁忌 | 无筷子/刀叉/勺子、无文字水印、无人手 |

## 十、重做执行要点（复用现有流程）

1. 生成：`ImageGen`，size `1536x1152`，prompt 固定模板
   `{菜名英文} overhead flat-lay food photography: {画面描述}, served in/on a wide shallow beige speckled ceramic bowl/plate, on a light warm wood-grain tabletop. Soft daylight from upper left, gentle shadow, glossy highlights, negative space. Ultra realistic, warm tones. No chopsticks, no cutlery, no text, no people.`
2. 去水印：工具输出右下角带「AI生成 WORKBUDDY」，统一裁掉底部 **80px**
3. 规格：居中裁 4:3 → 2400×1800 webp（q=84，约 300–500KB）
4. 入库：`scripts/_cq/import_dish_image.py --image <png> --dish <菜名> --crop-bottom 80`
5. 批量后重启容器并抽查 HTTP 200
